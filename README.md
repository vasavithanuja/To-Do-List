# TaskFlow – To-Do List

TaskFlow is a simple and user-friendly To-Do List web application designed to help users organize and manage their daily tasks.

## Features

- User Registration
- User Login
- Add New Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Active and Completed Task sections
- Task Priority
- Due Date
- User Profile
- Logout
- Responsive mobile-style UI

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- Git & GitHub
- GitHub Pages

## How to Run

1. Open the Live Demo link.
2. Register a new account.
3. Login using the registered email and password.
4. Add and manage your tasks.
